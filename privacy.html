Privacy Policy

Effective 28 October 2026

StarSwarm Agentic Security publishes the SGI Security Network (“SGI”) at starswarm-sgi.pages.dev. SGI is a browser security desk: a cover map, Analyze, Paste Guard, a threat index, study notes, and the other tools on that site. This page is the privacy policy for that site and for Google Sign-In on it.

Who we are

The publisher is StarSwarm Agentic Security. The product name on the site is SGI Security Network. The GitHub organization is StarSwarm-Security. Sponsorship is GitHub Sponsors. Support email: porschephotoshootz@gmail.com.

Device session

“Continue with this device” asks the SGI API for an anonymous session. This browser keeps a bearer session token in localStorage under the key sgi.session.v1 so a session that is still in date can skip the gate. The server stores a hash of that token, a device id, and an internal user id. That path does not ask for your name, email, or a password. The first device session also records a free plan and a 3-day Pro trial. The trial is not a charge.

Google Sign-In

If you choose Google Sign-In, Google sends an ID token. That token includes your Google account subject (sub) and, when Google includes it, your email address. We use the subject so the same Google account can sign in again. If an email is in the token, we accept the sign-in only when Google marks that email as verified. We do not write the email address into our database. We do not store the raw ID token. We never receive your Google password.

We do not sell that data, and we do not share Google user data with advertisers or use it to build an ad profile. We do not ask Google for anything beyond identifying the account for this sign-in. Google’s own policy describes what Google collects when you use their button: policies.google.com/privacy.

Analyze, Paste Guard, and other tools

  • Analyze and Paste Guard on the public site run in the browser. Paste Guard is built so the paste stays on the device. The public pages do not call the analyze API. If some other client does, the text is used to produce findings. A cache may store those findings and a hash of the input. There is no separate raw-paste column.
  • Swarm Pass keeps badges, streaks, and Swarm Credits in this browser. They are not money. An optional API snapshot can store that same ledger with the device id and user id. The Pass tab does not collect an email, a wallet, or an IP address for the ledger.
  • Bounty shows sample handles. Redeem is a preview: this build does not send gift cards and does not move XMR, SOL, ETH, or BTC.
  • Support chat answers from a FAQ file on the site unless that page is explicitly pointed at the API. Do not send passwords, keys, or payment data.
  • Quantum Helium can request public market data from CoinGecko in your browser. Honest Shield links out to other sites (VPN and malware-check tools). Those sites are not us and have their own policies. The threat index, hive, and study cards are files shipped with the site.

What we do not do

We do not sell personal data. The site does not ship a third-party analytics tracker and does not set an advertising cookie. Cloudflare Pages serves the site. The API is a Cloudflare Worker with a D1 database, so Cloudflare handles the connection as the host.

How long it stays

The browser copy of the session stays until it expires or you clear site data for this host. Server rows for a device or a Google subject stay until we delete them. There is no delete button in the app. Email porschephotoshootz@gmail.com or contact the StarSwarm-Security organization and name the device or Google account. We will remove the user, device, and session rows we can tie to that subject. Cached analyze findings are stored by hash, not under your name.

Children

SGI is not directed at children under 13. We do not knowingly collect personal information from them.
